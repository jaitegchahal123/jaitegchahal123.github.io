A.2 — Recover Homographies

Here, the [computeH] function computes the homography matrix between the 2 sets of points. Furthermore, I also implemented a helper function "pick_points" to visually aid in selecting points. The images below show the manually selected points on im2, as well as the homography matrix (H) * im1_points (red circles) which roughly equate to the selected im2_points (green circles).

The system of equations I used to solve the homography matrix: For each point (x,y) [the point to be transformed], (x', y') is the new, corresponding point on the other image.

System of Equations for Homography (DLT)

Given correspondences \( (x_i, y_i) \leftrightarrow (x'_i, y'_i) \) between the two images, we solve for a projective transform \( H \in \mathbb{R}^{3\times 3} \) up to scale (8 dof).

Perspective mapping
\[ \begin{aligned} \begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} \sim H \begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \;\;\Rightarrow\;\; x' &= \frac{h_{11}x + h_{12}y + h_{13}}{h_{31}x + h_{32}y + h_{33}},\\[2pt] y' &= \frac{h_{21}x + h_{22}y + h_{23}}{h_{31}x + h_{32}y + h_{33}}. \end{aligned} \] After solving, scale so that \(h_{33}=1\).
Linearized rows (per correspondence)
\[ \underbrace{\begin{bmatrix} x & y & 1 & 0 & 0 & 0 & -x'x & -x'y & -x' \\ 0 & 0 & 0 & x & y & 1 & -y'x & -y'y & -y' \end{bmatrix}}_{\text{rows for one point}} \underbrace{\begin{bmatrix} h_{11}\\h_{12}\\h_{13}\\h_{21}\\h_{22}\\h_{23}\\h_{31}\\h_{32}\\h_{33} \end{bmatrix}}_{h} = \begin{bmatrix}0\\0\end{bmatrix}. \] Stack these two rows for every \((x_i,y_i)\!\leftrightarrow\!(x'_i,y'_i)\).
Stacked system and solution
\[ A\,h = 0,\qquad A \in \mathbb{R}^{(2n)\times 9},\;\; h \in \mathbb{R}^{9}. \] Solve via SVD with \(\lVert h\rVert=1\): if \(A = U\Sigma V^\top\), then \(h\) is the last column of \(V\) (smallest singular value). Reshape to \(H\) and rescale so \(h_{33}=1\).

A.3 — Inverse Warping + Interpolation

In this section, I implemented Nearest Neighbor & Bilinear interpolation methods from scratch. We use these + warping to transform the actual image.

Nearest Neighbor interpolation rounds coordinates to the nearest pixel value; I noticed that this was faster, but the result was often much more pixelated. On the other hand, Bilinear interpolation uses a weighted average of 4 neighboring pixels; I noticed that this resulted in higher quality, however it took longer (increases comp. time). Below are each of the rectification images, using each interpolation-method.

For the implementation, I implemented both using for loops, and to speed up computation time, I often scaled/sized the input images (instead of vectorizing), and while Nearest Neighbor was much faster than Bilinear, both took some time.

A.4 — Blend Images into a Mosaic

To create the image mosaics, I used a Bilinear interpolation, on each image. For each set, since there were only 2-images, I would warp both to a chosen perspective (varies for each set).

The steps were to compute the homography matrix for each warp, and transform. Then, to determine the final canvas (for the entire mosaic), the corner coordinates for both images are projected through H, and hence, their combined min/max extents define the dimensions of the canvas. After warping the first image, we place the second image (unwarped) and is placed directly onto the canvas (with the same translation T). Lastly we compute Alpha Masks for blending (Binary Masks -> valid pixels (1) passed through distance transform). This way, our final output is smooth, and geometrically consistent.

B.1 — Harris Corner Detection

In this part, I run a single-scale Harris detector on each image after converting to grayscale, usually at half resolution for stability and speed. I compute the Harris response via the start code, but adjust threshold_rel and min_distance so the “no ANMS” overlay shows many corners without turning into a solid blob.

After collecting candidates, I apply Adaptive Non-Maximal Suppression. For each corner I measure the distance to the nearest stronger corner using a robustness factor of 0.9, then keep the points with the largest suppression radii (formula is in the paper/textbook). This produces a set of strong, well-spread features instead of clusters around textured areas. I save two figures at the working scale: raw Harris corners and the ANMS-filtered subset, and I print the counts so the reduction is clear.

B.2 - Feature Descriptor Extraction

Here, I extract simple axis-aligned patch descriptors centered at each ANMS keypoint. To make descriptors robust, I first reject points too close to the image border so a full 40×40 window fits. For each remaining keypoint I bilinearly sample a 40×40 grayscale patch on a regular grid centered at the point. I then apply a small Gaussian blur (sigma=1) to suppress pixel noise and minor misalignments before pooling. The pipeline becomes: 40→blur→pool→normalize->show.

B.3 - Feature Matching

In this part, I match descriptors using a simple nearest-neighbor ratio test (Lowe). I L2-normalize them and compute all pairwise squared L2 distances. For each descriptor in image A I find the best and second-best neighbors in image B and keep the pair only if the distance ratio is below a threshold (around 0.70 in the hard pair, slightly stricter in easier cases).

Next, I enforce mutual consistency by checking that A’s best match in B also picks that same point back in A. The result is visualized by drawing lines between corresponding keypoints on a side-by-side canvas.

B.4 - RANSAC for Robust Homography

In the final part, I implemented a 4-point RANSAC to make homography estimation robust to outliers in the descriptor matches at 5000 iterations. Each RANSAC trial samples four correspondences, rejects nearly collinear, and fits a candidate H with my normalized DLT function. I keep the model with the largest inlier set and then refit H once more using all inliers to reduce bias from the minimal sample.

To build panoramas from the recovered H, I first compute mosaic bounds so the warped image and the reference both fit on a common canvas. I warp with a bilinear sampler to get clean resampling and then paste the unwarped image onto the canvas. For blending I create soft alpha maps using a distance transform and do a weighted average.
